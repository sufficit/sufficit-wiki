# Publicação do manual de GitHub CLI e Radicle do Genius

Publicado o [manual público do Genius](https://wiki.sufficit.com.br/Genius/) no
commit `2be1ba2`. O texto em português cobre instalação pelo catálogo,
autorização do GitHub, uso no Linux, criação de conversas na nuvem pelo Android,
verificação dos comandos e retirada de permissões. O manual indica a limitação
observada para migrar uma conversa que começou localmente no Android.

O validador de links e os 14 testes do wiki passaram. A
[verificação de documentação](https://github.com/sufficit/sufficit-wiki/actions/runs/45854426147)
e a [publicação no GitHub Pages](https://github.com/sufficit/sufficit-wiki/actions/runs/45854425507)
terminaram com sucesso na revisão publicada.

O endereço `/Genius` redirecionou para `/Genius/` e a página respondeu HTTP 200.
Os links do índice geral e da seção Sufficit AI, as seis âncoras do sumário e
os exemplos de comandos foram conferidos no HTML público.
