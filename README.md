# Wiki Sufficit

Base pública de conhecimento do CRM/ERP Sufficit, um produto em desenvolvimento destinado à comercialização.

Este repositório centraliza documentação em Markdown sobre fluxos de negócio, funcionalidades, conceitos e regras de funcionamento para clientes, potenciais clientes, parceiros, integradores e equipes de suporte.

## Conteúdo previsto

- Contratação e controle de serviços.
- Renovação e recorrência.
- Cobrança, pagamentos e créditos.
- Cancelamento, estados e permissões funcionais.
- Integrações públicas, exemplos e perguntas frequentes.

A base está em estruturação. Esta lista indica os temas previstos; não afirma disponibilidade de funcionalidades no produto. Cada página deverá informar suas condições de disponibilidade e última revisão.

## Contribuições

Leia [AGENTS.md](AGENTS.md) antes de criar ou atualizar documentação. Descreva o comportamento verificado, use exemplos fictícios e preserve links entre assuntos relacionados.

Todo o conteúdo é público. Não inclua dados reais de clientes, credenciais, documentos privados ou detalhes de acesso à infraestrutura interna.
